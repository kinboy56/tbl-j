# pokeldn

pokeldn は、Nintendo Switch のローカル無線 (LDN) を実装したもので、市販の Switch 本体で動く
ポケモンのゲームと通信します。無線部には ESP32 ボードを使い、接続先はコンピューターや Android スマートフォンとの USB シリアル、または iPhone との Bluetooth です。
これらのページでは、関係するプロトコルを説明します。
逆コンパイルの引用、ディスアセンブリのアドレス、ハードウェアの測定値も載せています。

まずは [アプリのセットアップ](gui.md) か [コマンドラインでの使い方](usage.md) から始めてください。
[コードの構成](architecture.md) では、共有モジュールとテストを扱います。

## 対象ゲーム

市販の本体で動く 7 本のゲームは、いずれも同じ LDN と Pia の層の上で動きます。

| | FRLG | LGPE | SwSh | BDSP | PLA | SV | PLZA |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 交換 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| ふしぎなおくりもの | ✓ | ∅ | ✓ | ∅ | ∅ | ∅ | ∅ |
| イベントポケモン | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 通信対戦 | ✓ | ✗ | ✗ | ✗ | ∅ | ✗ | ✗ |
| 本体上でのコード実行、セーブの読み書き | ✓ | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ |

✓ 市販の本体で動作、✗ 未実装、∅ そのゲームにはローカル無線での該当機能がありません
FRLG ファイアレッド・リーフグリーン、LGPE Let's Go ピカチュウ・イーブイ、SwSh ソード・シールド、BDSP ブリリアントダイヤモンド・シャイニングパール、PLA Pokemon LEGENDS アルセウス、SV スカーレット・バイオレット、PLZA Pokemon LEGENDS Z-A

ファイアレッドとリーフグリーンは、Switch 上のエミュレーターで元の GBA ROM として動きます。そのため、ROM 自身の
GBA 通信プロトコルが、本体の LDN と Pia の上に重なります。残りの 6 本は、独自のコードを Pia の上に直接載せています。
ブリリアントダイヤモンド・シャイニングパールは Unity/IL2CPP、ソード・シールドと Let's Go ピカチュウ・イーブイは
`gflnet3` 経由でプロトコルバッファを使う C++ です。Pokemon LEGENDS アルセウス、スカーレット・バイオレット、
Pokemon LEGENDS Z-A は、Pia を静的リンクした C++ です。
