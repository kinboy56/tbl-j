# はじめに

pokeldn は、Switch または Switch 2 のポケモンゲームと、ローカル無線で交換を行います。USB 接続の ESP32 ボードが
無線機の役割を果たします。本体には何もインストールされません。

## 必要なもの

- USB シリアルブリッジを備えた従来型の ESP32 ボード (ESP32-D0WD, WROOM-32E)、または
  ESP32-S3、ESP32-C3、ESP32-C6 をネイティブ USB ポートで接続したもの。いずれも 2.4 GHz を使います。
  S2 のボードには対応していません。Seeed Studio XIAO ESP32C3 には付属のアンテナを取り付けてください。
  XIAO ESP32C6 は内蔵アンテナを使います。
- USB データケーブル。充電専用ケーブルではポートが表示されません。
- ご自身の Switch からダンプした `prod.keys`。アプリは初回に一度だけ求めます。
- Games ページにある 7 つのゲームのいずれか。

## 初回の実行

1. Board: ボードを接続し、Wireless の横にある Install を選びます。アプリがチップを検出してファームウェアを書き込み、続けてボードを自動で確認します。
   応答があるとページの上部に Up to date と表示されます。
2. Games: ゲームとツールを選びます。Host ツールは本体の参加を待ち、
   Join ツールは本体側の検索で見つけます。
3. 提供するポケモン: 種族を検索して Build を押します。PKHeX が、そのゲームで正規のポケモンを作成します。
   所有者は Settings のトレーナーになります。
4. 開始前に、Session パネルで不足している項目が表示され、それぞれに修正ボタンがあります。
   On the console の手順に従ってから、Start を押してください。

USB ポートを 2 つ備えた ESP32-S3、C3、C6 のボードは、USB と表示されたポートを通じてのみアプリと通信します。
もう一方のポート (COM または UART) から書き込むこともできますが、その場合ボードは応答しなくなります。Board ページにその旨が表示されます。
複数のボードを接続しているときは、Use this board で、セッションに使うボードを選べます。

種族の下の More options では、性格、特性、性別、持ち物、ボール、なつき度、個体値 (IVs)、努力値 (EVs) を設定できます
(Let's Go では AVs、Pokemon LEGENDS アルセウス では努力レベル)。空欄はランダムになります。
一覧には、その種族がそのゲームで正規に持てるものだけが表示されます。PKHeX が不正と判定した組み合わせは、理由とともに Build で拒否されます。
交換したポケモンのなつき度が保たれるのは、Settings の Your trainer が本体のプレイヤーである場合だけです。
ファイアレッド・リーフグリーンでは、交換のたびになつき度が 70 に設定されます。

ポケモンの下にある Add a trade では、1 回のセッションで最大 6 件まで交換を予約できます。完了した交換ごとに、次の予約が提示されます。
予約はすべての交換ツールに表示されます。交換で受け取ったポケモンは、それぞれ個別のファイルになります。

ファイルはアプリにドラッグできます。ポケモンのファイルや Showdown のチーム (`.txt`) を交換にドロップすると、その交換に読み込まれます。
Add a trade にドロップすると、ファイルごとに 1 件ずつ交換が予約されます。Gift カードにドロップしたギフトファイルは開かれ、
Board ページの Firmware カードにドロップした `.bin` は、確認後にインストールされます。

本体から送られたポケモンは `Documents/pokeldn/Received` に保存され、そのコピーが Bank にも保存されます。
Bank の + ボタンを押すか、グリッドにドロップすると、ポケモンのファイルまたはゲームのセーブデータ全体を取り込めます。
取り込んだデータに含まれる正規のポケモンは、それぞれ 1 回ずつ Bank に預けられ、ファイル自体はそのまま残ります。
古いゲームのポケモンを取り込むと、持ち物は残り、HM の技は忘れられます。これは HOME での取り込み方法に合わせた動作です。

## ストレージを空ける

Settings の Storage には、空けられる容量が表示されます。Clear local files を押してから Clear files を押すと、
保存済みのセッション記録、ログ、一時的なオファー、使われていない作成済みポケモンを削除できます。
不具合報告に必要な記録は、先に保存してください。Received のポケモン、選択中のオファー、鍵、ファームウェア、設定は残ります。
ファイルを消去する前に、現在の実行を終えてください。

## ファイアレッド・リーフグリーンの言語

Mystery Gift の Console カードには、バージョンと自動言語検出が表示されます。FireRed または LeafGreen を選んでください。
ゲームのともだちリストで pokeldn を選ぶと、ゲームがカートリッジのコードを報告します。pokeldn は、コードを送る前に、
そのカートリッジの言語に合わせたギフトスクリプトと RAM アドレスを選択します。両バージョンとも、英語、フランス語、ドイツ語、
イタリア語、スペイン語、日本語に対応しています。

ネイティブの `.wc3` を保存するとき、ギフトがバージョンや言語によって異なる場合は、そのカートリッジを尋ねられます。
`.pokegift` はすべての版を保持し、本体が接続したときに適したものを選びます。

Advanced の Trainer language は、通信相手となる pokeldn 側のトレーナーの言語を表します。
本体の言語を選ぶものではありません。

## Basic と Advanced

Basic には、ほとんどの実行で必要な項目が表示されます。各ゲームで検証済みの設定は、その下で適用されています。
Advanced には、そのゲームのセッションが受け付けるすべてのオプションが、それぞれのヘルプ文とともに表示されます。
ここで設定した値は Basic の項目より優先されます。ガイドや不具合報告で求められた場合を除き、変更しないでください。

ほとんどのプレイヤーが変更しない設定は、設定済みの状態で Advanced の上部にあります。セッションが自動で止まるまでの制限時間、
無線チャンネル、そして実行ごとの New PID です。New PID を有効にすると、提示する各ポケモンに新しい PID が割り当てられます。
そのため、同じポケモンを受け取ったことのあるセーブデータでも、もう一度受け取れます。イベントのポケモンなど PID を変えてはいけない
ファイルでは、オフにしてください。

## 自分のポケモンのファイル

Or use a Pokemon file では、PKHeX からエクスポートしたファイルを使えます。アプリは PKHeX でファイルを検査し、提示する前に正規かどうかを表示します。
不正なポケモンは、描画されたときに本体のゲームをクラッシュさせることがあります。

## ふしぎなおくりもの

各 Mystery Gift のツールは、4 つの選択肢から始まります。
Use a preset では、用意済みのギフトを送ります。
ソード・シールドでは、Official events に、検索ボックス付きで実際のイベントカード
(ポケモン、どうぐ、服、バトルポイント) が一覧表示されます。Build your own では、フォームが開きます。
ファイアレッド・リーフグリーンでは、文章、渡す相手、内容を含むふしぎなカード、ふしぎなニュース、または自分の ARM コードを作れます。
ソード・シールドでは、ポケモン、タマゴ、どうぐ、バトルポイントを作れます。
Open a file では、誰かが共有した `.pokegift`、ファイアレッド・リーフグリーンの `.wc3` カード、
またはソード・シールドの `.wc8` カードを送れます。

Customize を使うと、用意済みのギフトを変更できるフォームに変わります。Before you send には、本体が受け取る内容、受け取るタイミング、
対応するカートリッジが表示されます。問題があると、そこに赤字で表示され、Start は無効のままになります。

ファイアレッド・リーフグリーンでは、Game boosts で、速度を上げたりポケモンのフォロワーを追加したりするなど、ゲームの遊び方を変えられます。
ブーストを選んで送ってください。すぐに適用され、ゲームを再起動すると止まります。
再起動後にもう一度使うには、Save boosts for later を有効にしてブーストを送り、続けて Mom restores your boosts を送ります。
再起動するたびに、マサラタウンの自宅で母親に話しかけると、ブーストが再び有効になります。フォロワーは常に保存されます。
別のふしぎなカードを受け取ると、母親のギフトは置き換わります。
保存されたブーストを母親が再び有効にできるよう、もう一度送ってください。

Read the save では、結果が Session log に表示されます。Trainer ID (TID) は、トレーナーカードに記載された番号です。
Secret ID (SID) は通常、表示されません。パーティの表示には、最後に保存されたパーティの各ポケモンについて、性格、
6 つの個体値 (能力ごとの 0 から 31 までの値)、努力値 (EVs, 育成ポイント) が表示されます。
これらのツールは、セーブデータとふしぎなカードを変更しません。
トレーナー情報とパーティのツールは、読み取ったデータのコピーを Received にも保存します。

Console code は、ギフトを受け取る間にゲーム内で実行されます。Check offline では、まず模擬した本体上で実行されます。
メニューを止めてしまうコードは拒否されます。Native code は、実行中のゲームやそのセーブデータを変更できます。
出所と動作を確認したコードだけを送ってください。

Save gift file は、選んだギフトを再利用や共有のために保存します。ボードがなくても使えます。

ファイアレッド・リーフグリーンでは、Your save で、Switch のセーブデータ全体をこのコンピューターにコピーしたり、コピーを書き戻したりできます。
Back up from the Switch は、本体のセーブデータをそのまま残します。コピーは Your saves に、トレーナー名をつけて表示されます。
Put a save on the Switch は、選んだセーブデータを本体自身のセーブデータの横に書き込みます。
本体は各部分を確認してから読み込んで保存し、問題が起きた場合は以前のセーブデータを残します。
先に本体のバックアップを取ってください。復元は、PKHeX がパーティ全体を正規と判定するか、
Restore anyway をオンにするまで待機します。

Your saves は `Documents/pokeldn/Saves` に保存されます。名前を変えて区別したり、エミュレーターや PKHeX 用に `.sav` としてエクスポートしたりできます。
また、+ ボタンを押すか、カードにドロップして `.sav` を追加できます。
View and edit では、トレーナー、パーティ、PC のボックスを表示できます。お金やコインを変更したり、パーティのポケモンを並べ替えたり削除したりできます。
このセーブデータのトレーナー向けに作成したポケモンを追加したり、ボックスの正規性を確認したりできます。
Keep as a new save を選ぶと、結果は元のセーブデータの横に追加され、元のセーブデータは変更されません。

## 実行が失敗したとき

- 停止してから、本体の検索画面を抜けて、もう一度検索してください。
  多くのゲームでは、古いセッションが少しの間残ります。
- 1 回の実行では、変更を 1 つだけにしてください。
- Settings の Record every session と Open the records では、すべてのセッションの録画を確認できます。
  最新のものを不具合報告に添付してください。
