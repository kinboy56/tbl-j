# ファイアレッド・リーフグリーン

Switch 版のファイアレッド・リーフグリーンは、元の GBA 版 ROM をエミュレーターの中で動かしたものです。
そのため、2 つのリンク層が重なっています:

| 層 | 担当 | 解説場所 |
|---|---|---|
| LDN と Pia | エミュレーター側の担当で、他のすべての Switch タイトルと共通 | [無線層](ldn.md) |
| GBA のリンク: RFU フレーム、座席、ブロック送信 | ROM 側の担当 | 本ページ群 |

[pret/pokefirered](https://github.com/pret/pokefirered) が、`REVISION >= 0xA` におけるゲーム全体のプロトコルの正となる資料です。
カートリッジのヘッダーは両方の本体から読み取りました。
ソフトウェアバージョンは `0x0A`、ゲームコードは `BPRF` (ファイアレッド、フランス語版) と `BPGF` (リーフグリーン、フランス語版) です。
ホストは、英語・ドイツ語・イタリア語・スペイン語・日本語の各ペアについても、実測した ROM と RAM のアドレスを選択します。
カートリッジは合計 12 本です。
ふしぎなおくりものは、プレイヤーがともだちリストで pokeldn を選んだ後、カートリッジのコードから言語を判定します。
「基本」画面では、バージョンの横にこれが表示されます。
追加した言語については、オフラインの ROM 確認と mGBA での確認を済ませています。実機での検証の範囲は [実機での検証](frlg_rom_map.md#retail-verification) に載せています。
詳しくは [カートリッジのマップ](frlg_rom_map.md#the-international-revision-0x0a-cartridges) を参照してください。

Pia セッションが確定した後、アソシエーションから約 3 秒で離脱する本体は、
6、9、12 Mbit/s を含まないアソシエーション応答を受け取っています ([frlg_link.md](frlg_link.md)、広告される速度セット)。
Pia の type 2 Join Response が欠けている場合も、同じ症状になります。

## 動作する機能

実機では、両方のカートリッジで、ホストは本体が提供するすべての機能を動かせます。
ふしぎなおくりもの (両方向)、ホストとしてと参加者としての交換、リンクバトルを含むユニオンルーム全体、
ふしぎなニュース、通信対戦のコロシアム、訪問してくるバトルタワーのトレーナーです。

ふしぎなおくりもののリンクにある 2 つのインタープリターを通じて、本体は送られてきたコードも実行します。
その内容は、メモリの読み書き、実行中のビルド用に名前付き関数へ割り当てた本体の ROM、
8 個の引数で呼び出される本体自身の関数、
そしてホストが選んだポケモンを本体自身の `CreateMon` で作り、プレイヤーの手持ちに残すことです。
RNG は端から端まで解明されています。狙って出す色違いの出現は、1 回の試行につき A ボタンを 1 回押すだけで済みます。

ゲストからラッパーへの境界は解読済みです ([本体上のコード](frlg_rom.md#where-the-boundary-stands))。
領域の実体の末尾を越えて行うゲストの書き込みは 1 回だけで、
バイト単位まで正確で、値も一定です。
仕込まれたポインタを使う側は、`main` 自身のデータ内の静的アドレスから対象を読みます。
コンポーネントへのシステムコールによる書き込みは、件数と GBA アドレスとして読み戻され、
すべてのアドレスは範囲チェックされています。
ラッパー自身のスキャンパイプラインは、最初の段まで解読済みです ([ラッパー自身のスキャンパイプライン](frlg_rom.md#the-wrappers-own-scan-pipeline))。
スキャン結果、消費ループ、親候補リストは、どれも形が固定されて上限があります。
長さを受け取る唯一の経路 (駅名、最大 `0x40`) は、呼び出し元で上限に収められています。

## 2 本のカートリッジ

リーフグリーンは、区分ごとに一定のオフセットで同じコードを動かします。
実測したペアと境界は [リーフグリーン](frlg_leafgreen.md) に載せています。実測で挟まれていない境界をまたいでアドレスを予測しないでください。

## 全体に通じるルール

- decomp のリンク順は根拠になりますが、そのアドレスはカートリッジ上で実測する必要があります。
  `pokeldn/frlg/rom/rom_map.py` に、各アドレスの取得方法を記録しています。
- ペイロードは、送信する前に unicorn 上でオフラインに実行します (`buffer_script.emulate`、`emulate_repeating`、
  どちらも模擬した 2 つの本体)。異常終了するか、1 を返さずに終わるものは、
  ふしぎなおくりもののメニューを出口のない状態で止めます。ずっとループするフィールド用スタブは、フィールド画面を凍らせます。
